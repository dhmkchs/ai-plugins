argument-hint: [결정 주제, 예: "서버 상태 관리 도구 선택"]

`adr` 스킬을 사용해 진행한다. 스킬의 절차를 건너뛰지 말고 순서대로 따른다.

사용자가 전달한 결정 주제:
$ARGUMENTS

먼저 이 결정이 ADR 대상인지(되돌리기 비쌈 + 대안 둘 이상) 판정한다.
대안을 최소 둘, 각각 정직하게 적고 결과(비용)까지 남긴다.
비어 있으면 무슨 결정을 기록할지, 어떤 대안을 고려했는지 먼저 묻는다.
